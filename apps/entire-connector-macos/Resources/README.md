# Entire icon

`entire-symbol-dark-icon.svg` is the official 32px Entire icon from Entire's brand kit:

https://entire.io/downloads/entire-brand-kit.zip

It is used unchanged as a macOS template image so the system supplies the correct light/dark menu-bar color. Do not scale it above 32px or add effects; follow https://entire.io/brand/ when updating it.

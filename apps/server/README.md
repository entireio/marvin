# Marvin API

Fastify modular monolith: authenticated HTTP and WebSocket browser transport, identity adapters, canonical database and provider orchestration. Start through root `npm run dev` or `npm run build` / `npm start`. Environment validation is in src/config.ts. No credentials, repository contents or model prompts in routine request logs.

Host-scoped HttpOnly sessions, CSRF/origin checks, tenant ownership, normalized events, immutable origin routes, dispatch-time policy and lease-fenced persistence are enforced server-side. One API process is the supported live-stream topology for this slice. The device gateway supports authenticated WSS presence, body voice, owner enrollment and bounded remote intent; it does not make BLE a server transport. See the [current development checkpoint](../../docs/current-development.md) for active work and non-acceptance boundaries.

# Marvin portal

React/Vite personal conversation workspace. Run from root with `npm run dev`. Barlow/Barlow Condensed typography and neutral/blue technical styling align with the existing public docs while keeping separate routing and deployment. Locally bundled fonts; no remote analytics.

Native dialogs, keyboard network selection, responsive history, light/dark/reduced motion, escaped user text and safe Markdown are implemented. Browser voice and owner-authorized physical provisioning have implementation paths, but they are not production acceptance claims. The header also exposes an authenticated live remote when the linked Pet advertises the `remote` capability; it streams normalized drive/head intent rather than PWM values. See the [current development checkpoint](../../docs/current-development.md), root README and delivery status for verification boundaries.

# Marvin portal

React/Vite personal conversation workspace. Run from root with `npm run dev`. Barlow/Barlow Condensed typography and neutral/blue technical styling align with the existing public docs while keeping separate routing and deployment. Locally bundled fonts; no remote analytics.

Native dialogs, keyboard network selection, responsive history, light/dark/reduced motion, escaped user text and safe Markdown. Real microphone sessions and physical provisioning are unavailable until their later milestones; fixtures are explicitly labeled. See root README and delivery status for verification and limits.

Wi-Fi gets Marvin onto your network. This step tells it which server to talk to and gives it a password for doing so, so it can hold a conversation. Pressing the button writes three things to the robot over Bluetooth: the name you give it, the server address, and a token this server signs.

The token never appears on this page and is never shown in a form anyone could copy — it authorises a live microphone.

Quick:

Starting a conversation

Press Start listening next to a robot below, or say “Hey Marvin” on a board that can hear its own name. Marvin dips its head to show it is listening — on what it heard, not on a reply from the server, so the nod comes first.

Press Stop when you have finished speaking. That asks for the reply straight away instead of waiting for the AI service to decide the silence has gone on long enough.
